# ЧитAI

Курсова робота студентів групи ММТЕ-11.

Національний університет «Львівська політехніка»  
Інститут поліграфії та медійних технологій  
Кафедра мультимедійних технологій  
Дисципліна: «Мультимедійне видавництво»

## Опис проекту

«ЧитAI» — це веб-платформа для читання та інтелектуального пошуку книг з вбудованим асистентом «НейроЧат».

Мета проекту — показати, як мультимедійне електронне видання може поєднувати каталог книг, онлайн-читання та рекомендації на основі запиту користувача. Користувач може описати жанр, настрій, тему або бажаний сюжет, а нейробібліотекар підбирає відповідні книги та пояснює, чому вони підходять.

## Основні можливості

- каталог електронних книг;
- читання книг у браузері;
- інтелектуальний пошук за змістом, жанром, автором або настроєм;
- рекомендації книг через НейроЧат;
- картки книг з автором, жанрами, описом та переходом до читання;
- авторизація користувачів;
- можливість додавання книг до обраного.

## Призначення

Проект створено як навчальну курсову роботу з дисципліни «Мультимедійне видавництво». Він демонструє концепцію сучасної цифрової бібліотеки, де користувач взаємодіє не лише зі статичним каталогом, а й з інтелектуальним помічником для пошуку та вибору літератури.
